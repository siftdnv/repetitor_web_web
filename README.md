# Личный кабинет репетитора

Веб-приложение для частных репетиторов: управление расписанием, абонементами, финансами, домашними заданиями и ссылками на видеоплатформы в едином интерфейсе.

## Обоснование полезности

Проект решает проблему расфокусировки преподавателя, который вынужден вести расписание, учёт оплат и заметки в разных мессенджерах и блокнотах. Это приводит к забытым переносам, неоплатам и потере времени на переключение между платформами (Zoom, Google Meet, Discord, Телемост). Единый кабинет снижает финансовые потери от отмен и автоматизирует рутину.

## Что внутри репозитория

| Файл | Назначение |
| --- | --- |
| `generate_data.py` | Генератор синтетических данных (`seed`) |

| `analysis.py` | Скрипты анализа (`numpy`, `pandas`, `matplotlib`, 6 графиков) |
| `charts/` | Сгенерированные графики (`.png`) |
| `requirements.txt` | Зависимости проекта |
| `analysis_report.pdf` | Итоговый аналитический отчёт |

## Старт

Требуется Python 3.10+ (протестировано на 3.12):

```bash
pip install -r requirements.txt
python generate_data.py   # создание tutor_lessons.csv
python analysis.py        # запуск анализа и построение графиков
```

## Данные

**Данные синтетические.** Датасет моделирует работу 20 репетиторов со 150 учениками за 9 недель (сентябрь–октябрь 2026 г.) с учётом посещаемости по абонементам, платных поздних отмен (`<12 ч`) и отработок (`is_makeup`). Одна строка соответствует одному запланированному занятию. Непроведённые уроки (`completed == 0`) содержат причину (`cancellation_reason`), а рейтинг и статус ДЗ остаются пустыми (`NaN`).

| Колонка | Смысл | Тип / значения |
| --- | --- | --- |
| `lesson_id` | Идентификатор занятия | текст (`L0001` … `L1500`) |
| `tutor_id` | Репетитор | текст (`T001` … `T020`) |
| `student_id` | Ученик | текст (`S001` … `S150`) |
| `date` | Дата урока | `2026-09-01` … `2026-10-31` |
| `lesson_hour` | Время начала | текст (`11:00` … `20:00`) |
| `weekday` | День недели | текст (`Пн` … `Вс`) |
| `month` | Месяц | `сентябрь`, `октябрь` |
| `subject` | Предмет | текст |
| `goal` | Цель обучения | ОГЭ, ЕГЭ, школьная программа, олимпиады |
| `duration_minutes` | Длительность (мин) | `45`, `60`, `90` |
| `price_rub` | Стоимость урока (руб.) | целое число |
| `platform` | Платформа для созвона | `Zoom`, `Google Meet`, `Телемост`, `Discord` |
| `payment_type` | Формат оплаты | `абонемент`, `разовая` |
| `payment_status` | Статус оплаты | `paid`, `pending`, `unpaid` |
| `completed` | Статус проведения | `1` — проведён, `0` — отменён |
| `cancellation_reason` | Причина отмены | текст; пусто, если `completed == 1` |
| `is_makeup` | Доп. урок (возмещение) | `1` — отработка, `0` — обычный урок |
| `homework_completed` | Выполнение ДЗ | `1` или `0`; пусто, если `completed == 0` |
| `rating` | Оценка за урок | целое `1–5`; пусто, если `completed == 0` |
| `notes` | Заметки преподавателя | текст |
